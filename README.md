# SaaS Landing Page (Enterprice)

React + Vite build of the "sass-landing-page" Figma design.

## Run

```bash
npm install
npm run dev
```

## Images

All photos, icons, logos and store badges were exported from the Figma file and live in `public/images/`.
Swap any file there (same name) to change it.

## Structure

- `src/data.js` – all copy (cards, feature rows, FAQs, footer links)
- `src/components/` – Hero, Services, Feature, Security, Faq, Newsletter, Footer, Icons, Photo
- `src/index.css` – all styles (design tokens at the top)
